# Аудит реализации EnergoCheck по ТЗ

Дата проверки: 16.09.2026
Источник требований: `docs/PROJECT_SPEC.md`

## Сводка

Реализован ранний учебный каркас приложения и часть блоков 1, 2, 3, 8 и 9 в упрощенном виде. Текущий проект запускается на PostgreSQL 16 и использует только Django Templates и Bootstrap.

Полностью или частично покрыты:

- базовый Django-проект, разделенные настройки и подключение PostgreSQL;
- пользовательская модель с ролями `CONSUMER` и `EMPLOYEE`;
- базовый layout, главная страница и навигация;
- упрощенная карточка потребителя и ручное добавление показания;
- упрощенное создание счета по двум показаниям;
- регистрация платежа и смена статуса счета;
- базовая аналитическая страница;
- demo-скрипт для небольшой тестовой выборки.

Последний завершенный технический блок: серверная авторизация и ограничение служебных маршрутов ролью `EMPLOYEE`.

## Следующий порядок реализации

1. Разделить доменную модель на `SupplyObject`, `Contract`, `Meter`, расширенный `MeterReading`.
2. Реализовать ручную передачу показаний и очередь проверки.
3. Добавить OCR через отдельный recognizer adapter и fake для тестов.
4. Затем последовательно закрыть аномалии, начисления, уведомления, документы и остальные бизнес-блоки.
